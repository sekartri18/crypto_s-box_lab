Standard S-Boxes

Berikut adalah koleksi S-Box standard yang digunakan dalam berbagai cipher terkenal:

🔐 AES (Rijndael)

Bit: 8x8

Sifat:

  • NL: ~112
  • SAC: Good
  • DU: 4
  • AD: 7

S-Box dari Advanced Encryption Standard (NIST FIPS 197)

🔒 DES (S1)

Bit: 6x4

Sifat:

  • Original cipher
  • 6 input bits
  • 4 output bits
  • 16 S-boxes total

Salah satu dari 8 S-Box DES

🐍 SERPENT (S1)

Bit: 4x4

Sifat:

  • 32 S-boxes parallel
  • 4 input bits
  • 4 output bits
  • High security margin

Candidate untuk AES

🔑 TWOFISH

Bit: 8x8

Sifat:

  • Designed by Schneier
  • Variable S-boxes
  • High nonlinearity
  • Good diffusion

AES Candidate (runner-up)

  • Hardware efficient

📚 Teori Cryptanalysis Criteria

1. Nonlinearity (NL)

Mengukur jarak fungsi Boolean output dari linear/affine function.

NL = min{d(f, L) | L adalah linear affine function} dimana d adalah Hamming distance Interpretasi: - Semakin tinggi NL, semakin resisten terhadap linear cryptanalysis - Untuk 8-bit S-Box: Nilai > 100 dianggap good - AES: NL ≈ 112

2. Strict Avalanche Criterion (SAC)

Mengukur output bit change saat satu input bit dibalik.

SAC: Jumlah output bits yang berubah harus mendekati 50% untuk SETIAP single-bit input change Syarat: - Ideal: 50% ± 10% - Bad: Jika ada input bit yang selalu menghasilkan perubahan > 75% - Interpretasi: Baik untuk diffusion properties

3. Bit Independence Criterion (BIC)

Output bits harus independent satu sama lain.

BIC-NL: Nonlinearity dari XOR setiap pair output bits BIC-SAC: SAC dari XOR setiap pair output bits Tujuan: - Memastikan output bits tidak linear dependent - Meningkatkan resistance terhadap algebraic attacks - Nilai tinggi untuk BIC-NL dan 50% untuk BIC-SAC adalah ideal

4. Linear Approximation Probability (LAP)

Probability of best linear approximation.

LAP(a,b) = |#{x: a·x = b·S(x)}| / 256 dimana: - a: input mask - b: output mask - S(x): S-Box output - · : dot product Interpretasi: - Semakin kecil, semakin baik (ideal < 0.3) - max(LAP) menunjukkan resistance terhadap linear cryptanalysis

5. Differential Uniformity (DU)

Maximum frequency of output differences for given input difference.

DU = max{#{x: S(x) ⊕ S(x⊕a) = b} | a,b ≠ 0} Interpretasi: - Smaller is better (ideal ≤ 4 untuk 8-bit) - AES: DU = 4 - DU = 2 adalah optimal (Perfect Diffusion Layer) - Resist differential cryptanalysis

6. Algebraic Degree (AD)

Derajat aljabar dari Boolean function.

AD = highest degree term dalam algebraic normal form (ANF) Interpretasi: - Semakin tinggi, semakin baik (max = 8 untuk 8-bit) - AD ≥ 6 dianggap good - Resistance terhadap algebraic attacks - Low degree = vulnerable to algebraic attacks

7. Transparency Order (TO)

Mengukur transparansi atau balancing properties.

TO = |#{x: f(x) = 1}| - 128 Interpretasi: - Semakin kecil (mendekati 0), semakin balanced - TO = 0 artinya perfectly balanced (128 ones, 128 zeros) - Low TO = good resistance terhadap frequency analysis

8. Correlation Immunity (CI)

Independence dari subsets of input variables.

CI Order t: Jika output independent dari setiap t-subset dari inputs Interpretasi: - Higher order CI lebih baik - CI ≥ 1 berarti ada resistance terhadap correlation attacks - Trade-off dengan nonlinearity (higher degree)

🔧 Cara Membuat S-Box Berkualitas

Kriteria Desain:

  • Permutation: Setiap input mapping ke unique output (0-255)
  • Nonlinearity: NL > 100 untuk 8-bit
  • Avalanche: SAC ≈ 50% untuk semua input flips
  • Differential Resistance: DU ≤ 4
  • Algebraic Degree: AD ≥ 6
  • Balance: TO minimal (balanced)

Metode Pembuatan:

  1. Random/Heuristic:
    • Start dengan random permutation
    • Evaluate criteria
    • Apply local swaps untuk improve
  2. Algebraic Construction:
    • Gunakan inverses atau power maps
    • Contoh AES: S(x) = A·(x^-1) + c
    • Affine transformation untuk linearize
  3. Cryptographic Constructions:
    • Berdasarkan Boolean functions dengan known properties
    • Gunakan bent functions untuk high nonlinearity
    • Combine multiple properties

❓ Frequently Asked Questions

Q: Apa arti hasil "NL = 112"?

A: Rata-rata nonlinearity setiap output bit adalah 112. Artinya output bit setidaknya berjarak 112 (dari 256) dari fungsi linear manapun. Ini adalah nilai yang baik (mendekati AES).

Q: SAC saya 48%, apakah baik?

A: Ya, SAC 48% sangat baik. Nilai ideal adalah 50%, tetapi 48-52% masih diterima. Perbedaan 2% tidak signifikan.

Q: DU=6 untuk S-Box saya, apakah problem?

A: DU=6 sudah cukup baik tetapi tidak optimal. Ideal adalah DU ≤ 4. Jika ini critical, pertimbangkan re-design S-Box.

Q: Bagaimana cara improve Algebraic Degree?

A: AD ditentukan oleh struktur S-Box. Untuk improve:

  • Gunakan bent functions (AD maksimal)
  • Apply non-linear affine transformations
  • Pertimbangkan re-design dari scratch

Q: Apakah semua kriteria sama pentingnya?

A: Tidak. Untuk sebagian besar cipher, prioritas:

  1. Nonlinearity & Differential Uniformity (critical)
  2. SAC & BIC (important)
  3. LAP & AD (very important)
  4. CI & TO (additional security)
