👋 Selamat Datang!

Ini adalah tool komprehensif untuk menganalisis dan menguji kualitas S-Box (Substitution Box) menggunakan 9 kriteria kriptografis yang berbeda.

Aplikasi ini 100% offline, gratis, dan open untuk pendidikan dan penelitian.

🚀 Quick Start (3 Langkah)

Langkah 1: Buka Analyzer Klik tombol di bawah untuk membuka aplikasi utama.
Langkah 2: Input S-Box Masukkan 256 nilai S-Box Anda dalam format hex atau decimal. Anda dapat:
  • ✓ Mengetik langsung di text area
  • ✓ Copy-paste dari file lain
  • ✓ Upload file text
  • ✓ Gunakan contoh AES sebagai referensi
Langkah 3: Analyze Klik tombol "Analisis S-Box" dan lihat hasil lengkap dengan interpretasi dalam 4 step terstruktur.

🔍 Memahami Hasil Analisis

Quick Interpretation Guide:

Metrik Bagus Kurang Baik
Nonlinearity (NL) > 110 < 100
SAC 45-55% < 40% atau > 60%
Differential Uniformity ≤ 4 > 8
Algebraic Degree ≥ 6 < 4
Linear App. Prob. < 0.3 > 0.5
Correlation Immunity ≥ 1 = 0

📌 Contoh Workflow

Scenario 1: Testing AES S-Box

  1. Buka Analyzer → Klik "Contoh (AES)"
  2. Klik "Analisis S-Box"
  3. Lihat hasil: NL≈112, SAC≈50%, DU=4, AD=7
  4. Pelajari mengapa AES dianggap strong

Scenario 2: Testing Custom S-Box

  1. Siapkan 256 nilai S-Box Anda (0-255, unique)
  2. Copy-paste ke analyzer atau upload file
  3. Klik "Analisis S-Box"
  4. Review hasil dan bandingkan dengan AES
  5. Identify weaknesses dan improve design

Scenario 3: Research Paper

  1. Analyze multiple S-Boxes
  2. Export results (copy JSON dari tab Detail)
  3. Compare metrics dalam spreadsheet
  4. Include results dalam paper/thesis
  5. Cite tool dan methodology

💾 Format Input S-Box

Format 1: Hexadecimal

0x63 0x7c 0x77 0x7b 0xf2 0x6b 0x6f 0xc5 0x30 0x01 0x67 0x2b ... (256 values)

Format 2: Decimal

99 124 119 123 242 107 111 197 48 1 103 43 254 215 171 118 ... (256 values)

Format 3: Dengan Koma

0x63, 0x7c, 0x77, 0x7b, 0xf2, 0x6b, 0x6f, 0xc5, ... atau 99,124,119,123,242,...

Format 4: Multi-line (file format)

63 7c 77 7b f2 6b 6f c5 30 01 67 2b fe d7 ab 76 ca 82 c9 7d fa 59 47 f0 ... (256 values total)

✓ Semua format otomatis dideteksi dan diparse dengan benar!
